Handcrafted teddy bear adoption site: a static front-end plus a small serverless back-end that runs on Vercel. ``` index.html Storefront (hero certificate, bear gallery, adopt form, care, FAQ, contact) admin.html Workshop admin (adoptions, bears, messages, newsletter) css/ js/ Styles and front-end code api/ Back-end (Vercel serverless functions) bears.js GET public list of bears adopt.js POST adoption request (reserves the bear, optional Stripe checkout) subscribe.js POST newsletter signup contact.js POST contact form stripe-webhook.js POST Stripe events (marks paid / releases expired reservations) admin/ Login, data, bear CRUD, order status (password protected) _lib/ Store (Supabase or in-memory), auth, email, Stripe helpers db/schema.sql Tables and starter bears for Supabase dev-server.js Run everything locally: `node dev-server.js` ``` ## 1. Put it online (Vercel) 1. Upload all these files to your GitHub repo (keep the folder structure). Vercel redeploys automatically. 2. No `vercel.json` is needed. 3. The site works immediately with temporary in-memory data. Do steps 2 to 4 below to make it permanent. ## 2. Admin password (required for /admin.html) In Vercel: Project, Settings, Environment Variables. Add: | Name | Value | |---|---| | `ADMIN_PASSWORD` | a long password only you know | | `ADMIN_SECRET` | any long random string | Redeploy, then open `https://your-site.vercel.app/admin.html`. ## 3. Database (Supabase, free tier is fine) 1. Create a project at supabase.com. 2. SQL Editor, New query, paste `db/schema.sql`, Run. This creates the tables and the six starter bears. 3. Project Settings, API: copy the project URL and the **service_role** key. 4. Add to Vercel: `SUPABASE_URL` and `SUPABASE_SERVICE_KEY`. Never put the service key in front-end code. ## 4. Card payments (Stripe, optional) Without Stripe, an adoption request reserves the bear and emails you (and the family) so you can invoice them. 1. Add `STRIPE_SECRET_KEY` and `SITE_URL` (your full site address) to Vercel. 2. In Stripe, Developers, Webhooks, add endpoint `https://your-site.vercel.app/api/stripe-webhook` with events `checkout.session.completed` and `checkout.session.expired`. 3. Add the signing secret as `STRIPE_WEBHOOK_SECRET`. Use Stripe test keys first (card 4242 4242 4242 4242). ## 5. Email (Resend, optional) Add `RESEND_API_KEY`, `MAIL_FROM` (a sender on a domain you verified in Resend) and `OWNER_EMAIL` (where new adoptions and messages are sent). ## Run locally ``` ADMIN_PASSWORD=test ADMIN_SECRET=x node dev-server.js ``` Open http://localhost:3000. No packages to install. ## Things to review before launch - Testimonials, the "six makers" claim, material sourcing, and the FAQ answers are written from the original page and general assumptions. Replace anything that isn't true for your workshop. - Bears are edited in the admin (Bears tab). Prices, names, colours and stories all update the live site. - A reservation made through Stripe that the family abandons is released when Stripe sends the expiry event (about 24 hours). In the admin you can cancel an order at any time to release the bear. ```` ## FILE: package.json ````json { "name": "adoption-taddy", "version": "2.0.0", "private": true, "description": "Adoption Tales Co. storefront and API", "scripts": { "dev": "node dev-server.js" }, "engines": { "node": ">=18" } } ```` ## FILE: .env.example ````example # Copy these into Vercel: Project > Settings > Environment Variables. # --- Required for the admin panel --- ADMIN_PASSWORD=choose-a-long-password ADMIN_SECRET=any-long-random-string # --- Database (Supabase: Project Settings > API) --- SUPABASE_URL=https://xxxx.supabase.co SUPABASE_SERVICE_KEY=service_role_key_here # --- Optional: card payments (Stripe) --- STRIPE_SECRET_KEY=sk_live_or_test_key STRIPE_WEBHOOK_SECRET=whsec_xxx SITE_URL=https://adoption-taddy.vercel.app # --- Optional: email (Resend) --- RESEND_API_KEY=re_xxx MAIL_FROM=Adoption Tales Co. Caring for your bear

A little attention keeps a handmade bear soft for decades.

  • Spot clean only

    Dab with a damp cloth and a drop of mild soap. Don't machine wash or soak.

  • Air dry away from heat

    Pat dry with a towel and leave it to dry in the open air, not on a radiator.

  • Brush with the fibres

    A soft brush, moving the way the mohair lies, keeps the coat full.

  • Keep out of long sun

    Hand-dyed wools stay rich when they aren't left on a sunny windowsill all summer.

Questions about adopting

What name goes on the certificate?

Whatever family name you enter on the adoption form. You can also add a short gift message if the bear is for someone else.

How do I pay?

You pay by card at the end of the adoption form. If card payment isn't available, we email you an invoice and keep your bear reserved.

When will my bear arrive?

Every bear is packed by hand. We email you as soon as yours is on its way.

Is each bear really one of a kind?

Yes. Bears are made in small batches and never repeated exactly, so the bear you pick is the one you receive.

Can I adopt a bear as a gift?

Yes. Enter the name of the family receiving the bear and add your gift message in the form.

Talk to the workshop
